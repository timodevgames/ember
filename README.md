# Ember

A local-first web app (installable on iPhone) that tracks habits and food — and
turns them into a fox spirit that grows nine tails if you stay consistent, and
runs away into the forest if you don't.

```bash
npm install
npm run dev     # http://localhost:5180
npm test
```

See `docs/PLAN.md` for the full plan and `CLAUDE.md` for architecture notes.

Food data: Bundeslebensmittelschlüssel (BLS 4.0, Max Rubner-Institut) · Open Food Facts (ODbL).
